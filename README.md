## 日本語

項目を入力してスタートを押すだけで使える、12種類の抽選ツール集です。インストール不要で、PC・スマホの両方で使えます。

すべての処理はお使いの端末内で行われます。入力内容がどこかに送信されることはありません。

**👉 [今すぐ使う](https://daigorou-addon.github.io/lucky-draw/)**

### 抽選の種類

| 種類 | 内容 |
| --- | --- |
| ルーレット | 回転するルーレットで1つを選ぶ |
| あみだくじ | 「線をシャッフル」で線を引き直せる |
| レース | 項目が競走。乗り物は馬・ボート・車から選べる |
| くじ引き | 番号をタップして引く。残り数が表示され、リセットも可能 |
| ダーツ | ダーツを投げて決める |
| スロット | スロットを回して決める |
| チーム分け | 項目を指定したチーム数（2〜20）に振り分ける |
| ピンボール | ピンボールで決める |
| 福引き | 抽選転筒で決める |
| 玉落とし | 玉を落として決める |
| ビンゴ | ビンゴマシンを回して、1〜75の番号を1つずつ引く。引いた番号は番号盤に表示され、リセットも可能（項目の入力は不要） |
| ガチャ | ハンドルを回してカプセルを出し、開けて結果を見る |

### 共通の使い方

1. 左のメニューから抽選の種類を選びます。
2. 項目を1行に1つずつ入力します（2つ以上、1項目は全角16文字まで）。空欄のときは A〜D で抽選できます。
3. 「スタート！」を押します。

### その他

- 効果音のオン／オフを切り替えられます。
- 表示テーマ（ライト／ダーク）を切り替えられます。
- **6言語対応**（日本語 / English / 한국어 / 简体中文 / 繁體中文 / Español）

## English

LuckyDraw is a collection of 12 draw tools: enter your items and press start. No installation is required, and it works on both desktop and mobile.

Everything is processed on your own device. Your input is never sent anywhere.

**👉 [Try it now](https://daigorou-addon.github.io/lucky-draw/)**

### Draw types

| Type | Description |
| --- | --- |
| Roulette | Spin the wheel to pick one |
| Amidakuji | Ladder lottery, with a "Shuffle lines" button to redraw the lines |
| Race | Items race each other. Choose a horse, boat, or car |
| Box Draw | Tap a number to draw. Shows how many are left, and can be reset |
| Darts | Throw a dart to decide |
| Slot | Spin the slots to decide |
| Team Split | Split the items into the number of teams you choose (2–20) |
| Pinball | Let a pinball decide |
| Prize Drum | Spin the prize drum to decide |
| Peg Drop | Drop a ball to decide |
| Bingo | Spin the bingo cage and draw numbers from 1 to 75 one by one. Drawn numbers are shown on a board, and it can be reset (no items needed) |
| Gacha | Turn the handle to get a capsule, then open it to reveal the result |

### How to use

1. Choose a draw type from the menu on the left.
2. Enter one item per line (2 or more, up to 16 full-width characters each). Leave it empty to use A–D.
3. Press "START!".

### More features

- Sound can be turned on and off.
- Light/dark theme.
- **6 languages** (日本語 / English / 한국어 / 简体中文 / 繁體中文 / Español)
